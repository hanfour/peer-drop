PeerDrop 5.6.0 — reviewer notes

WHAT CHANGED SINCE 5.5.2
- Localization: the virtual-pet companion's labels (species, food, mood, life stage) are now localized across all five supported languages. They were previously hardcoded in Chinese for every locale. This is a data-only change to a string catalog — no behavior change.
- Security hardening (no user-visible change): the end-to-end encryption layer (Double Ratchet) now verifies message authentication BEFORE advancing session state, so a malformed or forged packet can no longer disrupt an established session. Separately, App Store builds no longer embed a relay-server API key — devices authenticate to the optional relay via Apple's App Attest instead.

NO NEW PERMISSIONS OR DATA
- No new entitlements or capabilities versus 5.5.2.
- No data collected. The Privacy Manifest is unchanged; the app still reports "Data Not Collected."

HOW TO EXERCISE THE APP
- The localized pet UI works fully offline and with no account: launch the app, complete the brief onboarding, open the "Pet" tab — the species / food / mood / life-stage labels render in the device's language.
- Peer-to-peer file transfer and voice calls require TWO devices, either on the same local Wi-Fi (direct) or over the encrypted relay (internet). A single-device review can fully verify launch, onboarding, and the localized Pet UI without any second device or account.

ARCHITECTURE (unchanged from prior reviews)
- Free, no accounts, no ads, rated 4+. Sharing is direct device-to-device over local Wi-Fi / Bluetooth, or an optional end-to-end-encrypted relay. Chat is end-to-end encrypted (X3DH + Double Ratchet). China is excluded from availability (prior CallKit Guideline 5.0 resolution).

Thank you for reviewing.
