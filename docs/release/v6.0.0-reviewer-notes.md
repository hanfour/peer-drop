# v6.0.0 — App Store Reviewer Notes (iOS)

**TL;DR:** 6.0.0 removes the pet companion feature (hatching, feeding, evolution, sprites, the home-screen widget and Live Activity). Nothing is added. On first launch the app deletes the pet data it previously stored on the device, in the app group and in the user's iCloud container. No new data collection; the app still collects no data.

## What changed in 6.0.0

- The "Pet" tab, the floating pet, the chat pet overlay and the upgrade screens are gone.
- The `PeerDropWidget` extension (pet widget + Live Activity) is no longer shipped; the app no longer declares `NSSupportsLiveActivities`.
- On first launch after updating, a one-time cleanup deletes the app's own leftover pet files: `Documents/PetData`, two files in the app group container, three iCloud key-value entries and the `PetData` folder in the app's iCloud Drive container. It does not touch chats, transfer history, trusted devices or any other user content.
- The iCloud and app-group entitlements are kept for this release only so that cleanup can run; they will be removed in the next release.

## What did not change

- Peer discovery (Bonjour / Bluetooth), SAS pairing, end-to-end encrypted chat (X3DH + Double Ratchet), file transfer, voice calls (PushKit + CallKit), relay, push notifications, App Attest device authentication.
- Tip Jar IAPs (tip.small / tip.medium / tip.large).
- Privacy Manifest — unchanged; the app still collects no data.
- Age rating (4+), supply regions (China excluded).

## How to verify

1. Install 5.6.0, open the Pet tab once (creates pet data), then update to 6.0.0.
2. Launch: the tab bar shows Nearby / Connected / Library only; no pet UI anywhere.
3. Chats, saved devices and transfer history from 5.6.0 are still present.
